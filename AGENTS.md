# PartsMarket Project

Build a beginner-friendly full-stack marketplace for selling used car parts.

## Technology

- React with Vite and JavaScript
- Node.js and Express
- MongoDB with Mongoose
- CommonJS require() syntax in the backend
- JWT authentication using HTTP-only cookies
- bcryptjs for password hashing
- Multer for image uploads
- Plain CSS for styling

## Features

- Register, login, and logout
- Users must log in to create listings
- View and search used-part listings
- Add, edit, and delete listings
- Upload product photos from the computer
- Users may edit and delete only their own listings
- Responsive desktop and mobile design

## Coding rules

- Use JavaScript, not TypeScript.
- Keep the code simple and easy for a student to explain.
- Use separate React components and pages.
- Use useState meaningfully in every main page.
- Never save passwords, MongoDB URLs, or JWT secrets in Git.
- Create .env.example without real secret values.
- Work on only the requested stage.
- Test changes before finishing.
- Explain every changed file in simple language.
